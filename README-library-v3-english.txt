Public Library Manager — English launch version

Open public-library-manager-v3-english.html in a modern browser.
The app is configured to open in English by default. If the app has a language toggle, Malayalam may still be available.

Important:
- This is a standalone browser prototype, not yet a Windows desktop app with SQLite.
- Data is stored in the browser's localStorage on this computer/browser profile.
- Back up data regularly before using real library records.
- Syntax-level changes do not guarantee full functional QA.
